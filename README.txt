KURDISTAN FORCE — Website starter
1) Unzip this folder.
2) Open index.html to preview locally.
3) Upload the contents of this folder to a GitHub repository.
4) In Netlify, choose Add new site > Import an existing project > GitHub.
5) Select the repository. Build command: leave empty. Publish directory: .
6) Deploy.

This is a front-end preview. It has language switching and local archive-card search.
It does not yet have user accounts, a database, an admin panel, or verified historical records.
The hero image is an AI-generated illustrative image. Replace it if you prefer a documentary photograph.
Before publishing historical entries, verify them and add citations/sources.
